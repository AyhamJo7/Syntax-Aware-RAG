# Support

Thanks for using **Syntax-Aware-RAG** — a retrieval-augmented generation system with syntax-aware chunking, hierarchical embeddings, and multi-granularity retrieval.

## Getting help

- **Usage questions & ideas** — open a [GitHub Discussion](https://github.com/AyhamJo7/Syntax-Aware-RAG/discussions) (or an issue if Discussions is not enabled).
- **Bugs** — open a [GitHub Issue](https://github.com/AyhamJo7/Syntax-Aware-RAG/issues) using the bug template. Include your Python version, a minimal reproduction, and the full traceback.
- **Feature requests** — open an issue with the feature template and describe the use case.

## Before opening an issue

1. Check the [README](README.md) for setup, configuration, and usage.
2. Search [existing issues](https://github.com/AyhamJo7/Syntax-Aware-RAG/issues?q=).
3. Confirm you are on a supported Python (3.11+) and that required API keys are set via environment variables.

## Security

Please do **not** report security vulnerabilities in public issues. See [SECURITY.md](SECURITY.md) for private disclosure.

## Response expectations

This is a research/portfolio project maintained on a best-effort basis — there is no commercial SLA.
